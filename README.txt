AI EMAIL REPLY ASSISTANT
========================

Project Description:
AI Email Reply Assistant is a web-based application that generates
AI-powered email replies based on the selected tone.

Available Tones:
1. Formal
2. Friendly
3. Polite

Project Structure:
- index.html
- style.css
- script.js
- backend/app.py
- backend/requirements.txt
- start_backend.bat

How to Run the Project:
1. Open the project folder.
2. Start the backend using start_backend.bat.
3. The backend runs on:
   http://127.0.0.1:5000
4. Open the frontend using the local server.
5. The frontend runs on:
   http://127.0.0.1:5500
6. Paste an email in the input box.
7. Select Formal, Friendly, or Polite tone.
8. Click Generate Reply.
9. The AI-generated reply will appear in the output area.

Features:
- AI-generated email replies
- Formal, Friendly and Polite tones
- Generate Reply
- Regenerate Reply
- Copy Reply
- Clear
- Character Counter
- Loading State
- Error Handling
- Mobile Responsive UI

Technologies Used:
Frontend: HTML, CSS, JavaScript
Backend: Python, Flask, Flask-CORS
AI: OpenAI API

Note:
The backend must be running before using the Generate Reply feature.
